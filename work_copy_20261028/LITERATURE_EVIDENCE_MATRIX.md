## 1. Summary of Literature Landscape

Existing scholarly literature on Large Language Model (LLM) autonomous web agents falls into four main paradigms:
1. **End-to-End Environment Benchmarks:** Evaluating task success rates across complex multi-page web applications (e.g., WebArena, WorkArena, AgentBench).
2. **Multimodal Visual Grounding:** Combining screenshots and Set-of-Mark visual bounding boxes to ground actions visually (e.g., VisualWebArena, SeeAct, WebVoyager).
3. **HTML Context Compression & Filtering:** Training specialized models or using heuristic trees to compress long HTML documents to fit prompt token limits (e.g., Mind2Web, WebAgent / HTML-T5).
4. **Statistical Foundations for Stratified Trials:** Gold-standard categorical inference methods for stratified clinical and randomized block trials (e.g., Agresti, Newcombe, Wilson).

### The Unaddressed Scientific Gap
Despite intensive evaluation of web agents, **no published study has experimentally isolated the information-delivery channel within identical DOM structures under single-variable control**. Existing benchmarks conflate visual styling, page length, domain logic, and markup representations. Furthermore, no study has examined the **DOM serialization gap**—the discrepancy between what exists in the webpage HTML/DOM and what survives client-side agent serialization into the LLM context prompt.

## 3. Systematic Synthesis of the Research Gap

Across all reviewed literature, four critical gaps exist that our research directly targets:

### Gap 1: Conflation of Layout, Visuals, and Markup
In WebArena [Zhou et al., 2024], Mind2Web [Deng et al., 2023], and VisualWebArena [Koh et al., 2024], agents navigate heterogeneous real-world websites where visual layout, color palette, page length, and DOM markup vary simultaneously. It is impossible to determine whether an agent failed due to complex visual geometry, noisy JavaScript, long token context, or uninformative DOM tags. **Our study holds visual appearance, typography, pricing, and JavaScript routing 100% constant across variants, isolating markup alone.**

### Gap 2: Accessibility as an "Engineering Shortcut" vs. Active Cognitive Signal
In WorkArena / BrowserGym [Drouin et al., 2024], the authors use Accessibility Trees (AXTrees) primarily as an engineering shortcut to reduce token context from 15,000+ tokens to ~400 tokens. They assume that accessibility markup aids agent reasoning. **However, no study has tested whether adding ARIA attributes to elements that already have clear visible text provides any additive benefit to an LLM.** If the LLM already understands `"Add to Cart"`, does `aria-label="Add SoundFlow Air 3 to cart"` improve task accuracy?

### Gap 3: The Unreported DOM Serialization Bottleneck
Modern web agent libraries (`browser-use 0.13.10`) employ client-side DOM simplification pipelines to fit LLM context limits. **No prior paper has audited these pipelines to verify whether claimed metadata channels actually reach the agent prompt.** We show that `DISABLED_ELEMENTS = {'style', 'script', 'head', 'meta', 'link', 'title'}` completely eliminates Schema.org JSON-LD and static metadata, while attribute whitelists strip custom `data-*` attributes unless explicitly overridden.

### Gap 4: Flawed Verifiers and Survivorship Inflation
Prior web benchmarks have suffered from loose verifiers (e.g. accepting any category product, awarding partial credit on incomplete checkouts, or passing empty carts) and survivorship bias (retrying failed runs until success). **Our study establishes hardened, deterministic, state-asserted verifiers that eliminate artificial ceiling effects.**
