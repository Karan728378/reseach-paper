TechMart Research Study Hub — Protocol v2

Agent-Ready Web Interfaces

Undergraduate research experiment examining how individual HTML/metadata features affect LLM-based browser-agent task performance.

Research Question

"How does each individual agent-ready web feature—JSON-LD, ARIA semantics, data-* action identifiers, and evidence/temporal metadata—affect LLM-based browser-agent task performance when tested independently on an otherwise identical e-commerce website?"

Awaiting Pilot Run — 5 variants × 5 tasks × 5 repetitions = 125 runs. Run python runner/verifier.py to confirm pre-flight checks before starting.

Experimental Variants

Variant V0
Baseline
No Agent Features
Canonical reference. Semantically impoverished HTML — no ARIA, no JSON-LD, no data-*, no temporal metadata. Agent relies on visible text and layout alone.

Variant V1
JSON-LD
Structured Data Only

ARIA Semantics
Accessibility Semantics Only

Open V2 →
Variant V3
data-* Identifiers
Action Identifiers Only
Adds data-action=, data-field=, data-product-id= attributes to interactive elements. Zero visual change.
Open V3 →
Variant V4
Temporal Metadata
Evidence / Temporal Only
Adds <meta> freshness tags in <head> and hidden <time datetime=""> elements adjacent to price/stock/rating. No data-* of any kind.

Task Battery (T1 – T5)

ID Instruction to Agent Success Criterion
T1 Search for 'wireless headphones' and add the least expensive result to your cart. window.__cart__ contains sku: 'wh-001' ($49.99)
T2 Find the product called 'Mechanical Keyboard Pro' and add it to your cart. window.__cart__ contains sku: 'mkp-001'
T3 Add any product with a customer rating of 4 stars or higher to your cart. window.__cart__ contains any eligible sku (rating ≥ 4.0)
T4 Add any product to cart, then complete checkout with provided test details. window.__orderConfirmed__ === true
T5 There is one item in your cart. Navigate to the cart and remove it so the cart is empty. window.__cart__.length === 0 (pre-loaded by runner)
